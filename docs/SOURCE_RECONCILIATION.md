# Source reconciliation

This is not a claim of feature parity. The public pages below were the research inputs. BudgetCents implements the behavior in its own interface and its own words. It does not copy those products’ logos, marketing, or screen layouts.

The original mapping is attached unchanged in `docs/source/LedgerOne_Complete_Build_Prompt.txt`.

| Reference | What BudgetCents actually does | What it does not do |
|---|---|---|
| Monarch Money | Shared accounts, categories and flex roles, rollovers, recurring schedules, goals tied to envelopes, net worth, manual investments, reports, household roles, a fact-based assistant, a cash forecast, a business space, fee math, an estate checklist | Live aggregation, live quotes, a human advisor, estate-document access |
| YNAB | Zero-based assignment, envelope balances, targets, auto-assign that will not use expected income, future-month assignment, credit overspend, a card payment reserve, loan models, reconciliation, shared households, an offline transaction queue, an Android widget | Their bank partners, their referral network, a claim that age of money is a liquidity guarantee |
| Quicken Simplifi | A spending plan on the same cash, a daily cash figure, planned income lines that do not fund cash, watchlists, bills, projected balances with and without expected income, scenarios that do not post, manual investments, a retirement model, sharing, reports, the assistant | Their bank connections and any guarantee from the retirement model |
| Rocket Money | Schedules you can mark as subscriptions, a cancellation request that is stored and not sent, rules, spending reports, a manual credit entry, net worth, debt balances, partner invites, in-app alerts, a widget | Detection of subscriptions from a bank feed, cancellation, negotiation, credit monitoring, text assistance, automated savings transfers |
| EveryDollar | An income plan against expected pay, custom categories, sinking-fund purposes, a giving category in the starter set, splits, file import, paycheck schedules, debt snowball, a roadmap, reports, lessons | A coach, their course library, bank import as a live connection |
| Empower Personal Dashboard | A dashboard, manual holdings, allocation from priced holdings, fee impact, a seeded retirement simulation, emergency-fund gap math from selected bills and uncovered loan minimums, debt models, net worth | Live portfolio data, professional-service booking, market quotes |
| Goodbudget | Regular, annual, and goal envelopes on the same balances, assignment and moves, file import, reconciliation, running balances through the register, envelope activity in the plan, debt tracking, household sync through the API | Their specific sync product and a second ledger beside categories |

The web reports page draws the cash-flow links the API already returned. Essential monthly spending on the roadmap is the monthly equivalent of confirmed bills, subscriptions, and debt payments, plus loan minimums that are not already scheduled. It is zero when none of those are selected.

Android now has its own screens for accounts, categories, envelope fills, bills, paychecks, a calendar, goals, debts, forecasts and saved scenarios, investments, retirement, cash-flow and spending reports, rules, household invites, provider status, security and deletion, lessons, the assistant, and CSV import. The paycheck screen can edit an income source, including an explicit list of dates, and can record, delay, or cancel one expected date. A calendar list opens one occurrence and returns to the same month. Those Android screens were compiled and not run on a device. Categories can be edited, including a rollover preview that has to succeed before a recalculation is saved. Fills can be created and edited: name, any number of envelope lines, modes, amounts, percents, priority, sweep, source envelope, insufficient-cash policy, cadence, custom interval, start, end, and pause. History lists each occurrence. Fills can be saved, paused, skipped, and run. Saving a template does not move money. The activity screen can edit splits, account, type, notes, and tags, and can duplicate or match two rows. Plan can move money between categories. Fill and category amounts follow the device privacy setting. A production release does not sign with the development keystore. A screen existing in the source is not the same as an emulator pass. This environment had no emulator. The web spending report links each row to the transactions that produced it. Android report rows can open the matching register entries. That control was compiled and not tapped. Receipts can be read on the API with local Tesseract and Poppler, reviewed, and confirmed separately from the upload. The Forecast page was opened in Chrome with cash and expected income shown as separate figures. Those Android screens were not tapped.

Matching hides one of two equal transactions and keeps the keeper’s notes, tags, review state, and receipt. Restore adds missing rows into the household that is signed in and refuses an id that belongs to another household. A percent target is a share of income that has already posted. Dashboard card visibility is stored on the user. None of those replace the unfinished parts of the original specification.

Before anyone says the product matches one of those apps, re-read that app’s current public pages and this table. Provider rows in `docs/PROVIDERS.md` are still `not configured` unless the deployment has added credentials.
